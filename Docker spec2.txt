🐳 Part 1: High-Performance Worker Configuration (Dockerfile.worker)

To process raw audio chunks efficiently, the background worker node must compile multi-stage media streams. This build installs FFmpeg natively on an optimized Python base image.
dockerfile
# Dockerfile.worker
FROM python:3.11-slim-bookworm

# 1. Install system utilities and multimedia engine (FFmpeg)
RUN apt-get update && apt-get install -y --no-install-recommends \
    ffmpeg \
    curl \
    build-essential \
    && rm -rf /var/lib/apt/lists/*

# 2. Set up application workspace context limits
WORKDIR /app

# 3. Cache python dependencies to maximize layer efficiency
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 4. Pull app scripts into runtime deployment target directories
COPY . .

# 5. Launch worker daemon polling loop
CMD ["python", "worker.py"]

📸 Part 2: Automated Portfolio Image Generation (exporter.py)

This addition to your backend script generates a highly professional, visually appealing image snapshot of the candidate's metrics. When a worker completes a job, it draws this scorecard on the fly and saves it as a static asset, providing an excellent shareable artifact for social media loops.
python
# exporter.py
import os
from PIL import Image, ImageDraw, ImageFont

def generate_social_share_card(session_id: str, score: int, persona: str, summary: str) -> str:
    """
    Generates a beautifully typeset 1200x630 (OG Image Standard) PNG snapshot 
    summarizing user stats for clear presentation on LinkedIn / X.
    """
    # 1. Setup canvas background geometry (Dark Tech Aesthetic)
    width, height = 1200, 630
    img = Image.new("RGB", (width, height), color="#0F172A") # Slate-900 canvas base
    draw = ImageDraw.Draw(img)
    
    # 2. Initialize typographic font scaling limits
    # In production deployment, replace with explicit path targets to TrueType configurations (e.g., Arial, Inter)
    try:
        font_title = ImageFont.truetype("DejaVuSans-Bold.ttf", 46)
        font_score = ImageFont.truetype("DejaVuSans-Bold.ttf", 96)
        font_label = ImageFont.truetype("DejaVuSans.ttf", 24)
        font_body = ImageFont.truetype("DejaVuSans.ttf", 28)
    except IOError:
        # Fallback metric framework if default vector file layers are unmounted
        font_title = font_score = font_label = font_body = ImageFont.load_default()

    # 3. Draw branding accents & framing elements
    draw.rectangle([30, 30, width-30, height-30], outline="#334155", width=2) # Border casing
    draw.text((60, 60), "SPEECH-TO-CODE INSIGHTS // ALIGNMENT LABS", fill="#38BDF8", font=font_title)
    
    # 4. Render big performance score graphic
    draw.text((60, 180), "COHERENCE", fill="#64748B", font=font_label)
    draw.text((60, 210), f"{score}/100", fill="#38BDF8", font=font_score)
    
    # 5. Render tactical candidate persona classification block
    draw.text((450, 180), "PERSONA TYPE", fill="#64748B", font=font_label)
    persona_clean = persona.replace("_", " ")
    draw.text((450, 230), persona_clean, fill="#10B981", font=font_body)
    
    # 6. Typeset automated textual summary brief with simple word wrapping
    draw.text((60, 400), "EVALUATION SNAPSHOT:", fill="#94A3B8", font=font_label)
    
    words = summary.split()
    lines = []
    current_line = []
    for word in words:
        current_line.append(word)
        if len(" ".join(current_line)) > 65:
            current_line.pop()
            lines.append(" ".join(current_line))
            current_line = [word]
    lines.append(" ".join(current_line))
    
    y_cursor = 440
    for line in lines[:3]: # Restrict constraints to top 3 structured output lines
        draw.text((60, y_cursor), line, fill="#F8FAFC", font=font_body)
        y_cursor += 40

    # 7. Persist export to static public distribution mount paths
    output_dir = f"/tmp/sessions/{session_id}"
    os.makedirs(output_dir, exist_ok=True)
    export_filename = f"{output_dir}/share_card.png"
    img.save(export_filename)
    
    print(f"[Exporter] Shareable portfolio social card created at: {export_filename}")
    return export_filename
